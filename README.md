# Mood Pulse

A lightweight mood log that lets you track how you feel with a single tap. Pick a mood button and the app records the date and time automatically. Keep tapping the same mood to build its intensity—from a whisper (1) to an overwhelming feeling (20 and beyond).

## Features

- Quick mood capture with six ready-to-go feelings
- Automatic date and time stamping on the first tap
- Consecutive taps on the same mood increase the intensity counter
- Colorful history list that lives in your browser with localStorage persistence
- Clear log option when you want to start fresh

## Getting started

Open `index.html` in your browser. No build step or account required.

### Optional: run a local server

Some browsers limit localStorage when viewing files directly. To avoid that, serve the project locally:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
